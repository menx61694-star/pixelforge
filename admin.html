Observed public IPs are encrypted with AES-256-GCM before storage and decrypted only for authorized admins. Only the hosting edge cf-connecting-ip header is trusted. Local/private LAN IP is shown only when a visitor explicitly consents and their browser exposes it via WebRTC. It is browser-reported and unverified; many browsers mask it. VPNs, carrier NAT and proxies may affect the observed public IP. Manual deletion removes all current security logs; automatic retention removes logs older than 90 days.

WORKSPACE CONFIGURATION

Site settings

Settings are loaded securely for administrators.

Website identity

Maintenance mode

When enabled, the public homepage and Document Library show the maintenance screen.

Homepage knowledge corner

Use one fact per line in CATEGORY | FACT format. Up to 50 facts; each fact should be 8–240 characters. Visitors can request another fact with the refresh button.

Daily Quiz

Add up to 100 questions. Each object needs id, category, publishDate (YYYY-MM-DD), published, question, exactly four options, correctIndex (0–3), and explanation. Only a published question scheduled for today's India date is shown publicly. Correct answers are checked by the server.

Homepage Layout Manager

Keep all 11 section IDs exactly once. Set enabled to false to hide a section. Optional title/subtitle overrides are plain text. Reorder objects in the array to change homepage order; the hero and highlights strip stay fixed at the top.

SEO Management

Add up to 20 page overrides. Page paths must be local paths beginning with /. Robots options: index,follow; noindex,follow; noindex,nofollow. Titles and descriptions must meet the limits above.

User Feedback

Learning Corner

Add up to 12 paths, each with 1–8 steps. Levels: beginner, intermediate or advanced. Every step needs a title and HTTPS URL. Reorder paths and steps in the JSON to change their display order.

Smart Document Search

Announcements

Add up to 20 notices. Type must be info, update or important. Use India dates (YYYY-MM-DD); only published notices within their start/end dates appear. Optional links must use HTTPS.

Featured Resources

Add up to 12 resources in display order. Each needs a unique id, title, description, category, HTTPS URL, link label and published status. Set published to false to keep a draft hidden.

Quick Digital Tools

Allowed IDs: calculator, percentage, word-counter, unit-converter. Remove an ID to hide it; reorder lines to change display order. Tools run locally in the visitor’s browser.

Automatic sync preferences

These preferences are stored only; they do not independently start background sync jobs.
