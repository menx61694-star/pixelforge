RESTRICTED SECURITY DATA

Visitor security logs

Observed public IP and any location explicitly shared by a visitor after browser permission and consent. Coordinates are restricted to authorized security-log viewers. Logs are automatically deleted after 90 days.

Observed public IPs are encrypted with AES-256-GCM before storage and decrypted only for authorized admins. Only the hosting edge cf-connecting-ip header is trusted. Local/private LAN IP is shown only when a visitor explicitly consents and their browser exposes it via WebRTC. It is browser-reported and unverified; many browsers mask it. VPNs, carrier NAT and proxies may affect the observed public IP. Manual deletion removes all current security logs; automatic retention removes logs older than 90 days.

Maintenance mode

Homepage knowledge corner

Use one fact per line in CATEGORY | FACT format. Up to 50 facts; each fact should be 8–240 characters. Visitors can request another fact with the refresh button.

Popular Resources

Ranking uses real opens of published library documents. A browser session counts at most once per resource per day. Resources with no qualifying opens are not shown.

Document Library

Applies only to published public PDFs from PixelForge Storage and Google Drive. Private Vault files are excluded. The Open document link remains available as a fallback.

SEO Management

Default SEO details apply site-wide. Page-specific SEO customization will be available through a simple page manager instead of manual JSON.
